# Contributing to Awesome Angel Investors & Early-Stage VCs

We welcome contributions from founders, angel investors, and venture capital partners.

## Guidelines
1. **Factual Verification**: Every investor added must have verified early-stage check-writing activity (SEC Form D, official portfolio listing, or announced funding lead).
2. **Format**: Follow the existing table structure (Firm Name, HQ, Check Size, Stage, Sector, Source).
3. **No Fluff**: We aim to deliver the highest signal-to-noise ratio for early-stage founders.

## Pull Request Process
1. Fork the repo and create your branch from `main`.
2. Update the README table.
3. Submit a PR titled `Add/Update [Investor Name]`.
